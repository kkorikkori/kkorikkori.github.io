# Companion Persona Migration Is Not Monolithic

This post introduces a lightweight MVP for studying companion persona migration through longitudinal human–LLM dyad data and LoRA-based post-training.

The central claim is that companion persona migration should not be treated as a monolithic transfer problem. Some interactional micro-mechanisms may be partially captured through lightweight post-training, while long-term continuity, relational history, soft landing, and relational safety remain separate modeling problems.

## Public research scaffold

The accompanying GitHub repository will include:

- MVP report
- framework and pipeline figures
- public evaluation rubric
- synthetic examples
- privacy statement
- release boundary
- limitations

## Release boundary

The private dyadic conversations and trained LoRA adapter are not released. This public release focuses on the research framework, evaluation logic, synthetic examples, and ethical release boundary.
